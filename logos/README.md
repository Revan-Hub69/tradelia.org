# Logo Tradelia AI

## File Disponibili

### Logo Principale
- `tradelia-logo.svg` - Logo completo con testo "Tradelia AI" (240x60px)
  - Utilizzato nell'header del sito
  - Design moderno con gradiente blu istituzionale
  - Include icona "T" stilizzata e elementi di visualizzazione dati

### Icona
- `tradelia-icon.svg` - Icona standalone (512x512px)
  - Utilizzata per favicon e icone PWA
  - Design circolare con gradiente
  - Rappresenta la "T" di Tradelia con elementi di network/data visualization

## Design Philosophy 2025

Il logo Tradelia AI è stato progettato seguendo i principi del design istituzionale accademico 2025:

1. **Minimalismo Funzionale**: Design pulito e riconoscibile
2. **Gradiente Blu Istituzionale**: Colori che trasmettono professionalità e fiducia
3. **Elementi di Data Visualization**: I punti e le linee rappresentano l'analisi dati e l'AI
4. **Scalabilità**: SVG vettoriale per perfetta qualità a qualsiasi dimensione
5. **Accessibilità**: Alto contrasto e leggibilità garantita

## Utilizzo

## Formati

Tutti i file sono in formato SVG per:
- Scalabilità perfetta
- Dimensioni file ridotte
- Supporto moderno browser
- Facile personalizzazione
