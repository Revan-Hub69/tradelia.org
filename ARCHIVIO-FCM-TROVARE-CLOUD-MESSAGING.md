# 🔍 Come Trovare Cloud Messaging in Firebase

## Opzione 1: Menu Laterale (Creazione)

1. Nel menu laterale sinistro, cerca **"Creazione"** (Build in inglese)
2. Espandi la sezione "Creazione" (clicca sulla freccia se è chiusa)
3. Cerca **"Cloud Messaging"** nella lista
4. Se non lo vedi, prova l'**Opzione 2**

---

## Opzione 2: Impostazioni Progetto

1. Clicca sull'icona **⚙️** (Impostazioni) in alto a destra
2. Vai su **"Impostazioni progetto"** (Project Settings)
3. Vai alla tab **"Cloud Messaging"** (dovrebbe essere nella parte superiore)
4. Qui puoi vedere e configurare Cloud Messaging

---

## Opzione 3: Cerca nella Barra Superiore

1. In alto, c'è una barra di ricerca
2. Digita **"Cloud Messaging"** o **"Messaging"**
3. Clicca sul risultato

---

## Opzione 4: Abilitare Cloud Messaging API

Se Cloud Messaging non è ancora abilitato:

1. Vai su **"Impostazioni progetto"** (⚙️)
2. Vai alla tab **"Cloud Messaging"**
3. Se vedi **"Enable Cloud Messaging API"**, cliccalo
4. Oppure vai su: https://console.cloud.google.com/apis/library/fcm.googleapis.com
5. Seleziona il progetto Firebase
6. Clicca su **"Enable"**

---

## Cosa Cercare

Una volta che trovi Cloud Messaging, cerca:
- **"Web Push certificates"** o **"Certificati push web"**
- **"Generate key pair"** o **"Genera coppia di chiavi"**
- **"VAPID key"** o **"Chiave VAPID"**

---

## Se Non Lo Trovi

Se non riesci a trovare Cloud Messaging:
1. Assicurati di essere nel progetto corretto (`tradelia-push`)
2. Controlla che il progetto sia completamente creato
3. Prova a ricaricare la pagina
4. Usa la barra di ricerca in alto
