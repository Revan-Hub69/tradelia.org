# Immagini Community Facebook

Questa cartella contiene le immagini ufficiali delle community Facebook consigliate.

## File Richiesti

- `economia-investimenti.jpg` - Immagine per "Economia ed Investimenti Finanziari"
- `unionetrader.jpg` - Immagine per "Unionetrader" (ex Trader Italiani)
- `fufflix.jpg` - Immagine per "Fufflix"

## Specifiche Immagini

- **Formato**: JPG, PNG o WebP
- **Dimensioni consigliate**: 400x400px (quadrato) o 800x400px (rettangolare)
- **Peso**: Max 200KB per ottimizzazione
- **Aspect Ratio**: 1:1 (quadrato) o 2:1 (rettangolare)

## Come Aggiungere

1. Carica le immagini ufficiali in questa cartella
2. Rinomina i file secondo i nomi indicati sopra
3. Le immagini verranno automaticamente visualizzate nelle card delle community

## Fallback

Se un'immagine non è disponibile, verrà mostrata un'icona SVG di fallback (Facebook icon).
