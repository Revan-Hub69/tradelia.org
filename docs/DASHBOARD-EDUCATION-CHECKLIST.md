## 🔍 LACUNE ACCADEMICHE IDENTIFICATE

### 🚨 **CRITICHE**

#### **1. Font Weight Eccessivo**

**File**: `education-dashboard.css`, `education.css`, `dashboard.css`

- **Problema**: Uso di `font-weight: 700`, `800`, `900` in più punti
- **Best Practice Accademica**: Max `600` per titoli, `500` per sottotitoli
- **Occorrenze**: ~20+ istanze trovate
- **Esempi**:
  - `.lesson-view-content h1, h2, h3 { font-weight: 700; }`
  - `.module-title { font-weight: 700; }`
  - `.stat-value { font-weight: 800; }`

#### **2. Border Radius Eccessivo**

**File**: `education.css`, `education-dashboard.css`, `dashboard.css`

- **Problema**: Uso di `border-radius: 12px`, `14px`, `20px`
- **Best Practice Accademica**: Max `8px` per cards, `6px` per badges
- **Occorrenze**: ~15+ istanze trovate
- **Esempi**:
  - `.education-module-card { border-radius: 12px; }`
  - `.lesson-view-content { border-radius: 12px; }`
  - `.account-banner { border-radius: 14px; }`

#### **3. Gradienti Non Accademici**

**File**: `education-dashboard.css`, `dashboard.css`, `education.css`

- **Problema**: Uso di `linear-gradient` per backgrounds
- **Best Practice Accademica**: Solo colori solidi, no gradienti
- **Occorrenze**: ~5+ istanze trovate
- **Esempi**:
  - `background: linear-gradient(90deg, var(--edu-primary), var(--edu-success));`
  - `background: linear-gradient(135deg, var(--dash-blue-line), var(--dash-accent));`
  - `--dash-surface-shiny: linear-gradient(135deg, #1f1f1f 0%, #1a1a1a 100%);`

#### **4. Transform Scale su Hover**

**File**: `education-dashboard.css`, `education.css`

- **Problema**: Uso di `transform: scale(1.05)` su hover
- **Best Practice Accademica**: No transform su hover, solo colori/border
- **Occorrenze**: ~3+ istanze trovate
- **Esempi**:
  - `.module-card:hover { transform: scale(1.05); }`
  - `.lesson-item:hover { transform: scale(1.05); }`

#### **5. Box Shadow con Glow**

**File**: `dashboard.css`

- **Problema**: Uso di `box-shadow` con `var(--dash-accent-glow)`
- **Best Practice Accademica**: Shadow minimale, no glow
- **Occorrenze**: ~2+ istanze trovate
- **Esempi**:
  - `box-shadow: 0 0 4px var(--dash-accent-glow);`

### ⚠️ **MEDIE**

#### **6. Letter Spacing Eccessivo**

**File**: `education-dashboard.css`

- **Problema**: Uso di `letter-spacing: -0.02em` in alcuni titoli
- **Best Practice Accademica**: Max `-0.01em` per titoli grandi
- **Occorrenze**: ~5+ istanze trovate

#### **7. Line Height Non Ottimale**

**File**: `education-dashboard.css`, `education.css`

- **Problema**: Alcuni elementi con `line-height: 1.2` (troppo stretto)
- **Best Practice Accademica**: Min `1.4` per titoli, `1.5-1.7` per paragrafi
- **Occorrenze**: ~10+ istanze trovate

#### **8. Hyphenation Inconsistente**

**File**: `education-dashboard.css`, `education.css`

- **Problema**: Alcuni elementi con `hyphens: auto` invece di `manual` o `none`
- **Best Practice Accademica**: `hyphens: manual` per body, `none` per titoli
- **Occorrenze**: ~3+ istanze trovate
- **Esempi**:
  - `.education-section-title { hyphens: auto; }` (dovrebbe essere `none`)

#### **9. Console.log Non Standardizzato**

**File**: `global-search.js`, altri file

- **Problema**: Uso di `console.log/warn/error` invece di `safeLog`
- **Best Practice Accademica**: Usare sempre `safeLog` per logging centralizzato
- **Occorrenze**: ~10+ istanze trovate
- **Esempi**:
  - `console.warn("[GlobalSearch] manifest.json non trovato");`
  - `console.error("[GlobalSearch] Errore ricerca report:", e);`
