# Dashboard Improvements Roadmap
## Issues Identificati e Soluzioni

**Data:** 2025-01-27

---

## 🎯 ISSUES IDENTIFICATI

### 1. **Panoramica Dashboard - Componenti Non Visibili**
**Problema:** L'utente non vede tutte le componenti nella panoramica  
**Causa:** Tutte le componenti sono visibili ma richiedono scroll  
**Soluzione:** Sistema di personalizzazione drag & drop + show/hide

### 2. **Eventi Economic Calendar - Manca Corporate**
**Problema:** Solo eventi economici, mancano earnings e eventi corporate  
**Soluzione:** Estendere calendar o creare sezione separata "Corporate Events"

### 3. **Traduzione AI Automatica**
**Problema:** Molti contenuti arrivano in inglese (RSS, API, etc.)  
**Soluzione:** Traduzione automatica AI per tutti i contenuti esterni

### 4. **Tooltip Indicatori Mancanti**
**Problema:** Nessun tooltip con spiegazioni accademiche  
**Soluzione:** Tooltip su ogni indicatore con:
- Cosa fa
- Come si usa
- Studi accademici di riferimento

### 5. **Header Z-Index Troppo Alto**
**Problema:** Header copre la chat (z-50)  
**Soluzione:** Ridurre z-index header o aumentare chat

### 6. **Chat Behavior Issues**
**Problemi:**
- Si apre con tastiera aperta
- Si apre anche senza premere input
- Mostra vecchie conversazioni invece di nuova
- Manca cronologia per selezionare chat precedenti

**Soluzioni:**
- Aprire con tastiera chiusa
- Aprire solo su click input
- Sempre nuova conversazione su pagina principale
- Cronologia chat personali
