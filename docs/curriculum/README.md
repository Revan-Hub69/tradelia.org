# Curriculum Accademico Tradelia AI - Versione Completa

## Struttura Documentazione

Questa directory contiene la documentazione accademica rigorosa per i percorsi formativi retail, con livello di dettaglio equivalente al Modulo 2 (Risk Management).

### File Principali

- `evidence-review.md` - Review sistematica della letteratura accademica (20+ paper)
- `needs-evidence-mapping.md` - Mappatura bisogni reali → evidenze accademiche
- `percorso-risparmio-completo.md` - Specifica completa Percorso Risparmio/PAC (8 lezioni)
- `percorso-gruzzoletto-completo.md` - Specifica completa Percorso Gruzzoletto (8 lezioni)
- `percorso-speculazione-completo.md` - Specifica completa Percorso Speculazione (10 lezioni + 5 specializzazioni)

### Metodologia

Tutti i percorsi seguono:

1. **Evidence-Based Design**: Basati su paper accademici peer-reviewed
2. **Backward Design** (Wiggins & McTighe): Obiettivi misurabili → assessment → contenuti
3. **Bloom's Taxonomy Revised** (2001): Progressione cognitiva strutturata
4. **Learning Analytics** (Siemens & Long, 2011): Metriche di successo quantificabili
5. **Modello Modulo 2**: 6-8 lezioni dettagliate con quiz, objectives, reflections, esempi, case studies

### Livello di Dettaglio

Ogni lezione include:

- **Quiz Start** (3 domande): Attivare conoscenza precedente
- **Learning Objectives** (4-6): Obiettivi misurabili espliciti
- **Contenuto Dettagliato**: Teoria + esempi pratici + calcoli
- **Quiz Checkpoint** (2 domande): Verifica comprensione intermedia
- **Case Studies**: Esempi reali analizzati
- **Esercizi Pratici**: Calcoli, simulazioni, toolkit
- **Quiz End** (5-7 domande): Verifica apprendimento
- **Reflection Prompts** (Pre 2, Post 3): Metacognition
