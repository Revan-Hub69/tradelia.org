# Icone PWA

## Icone Necessarie

Crea le seguenti icone per la PWA (Progressive Web App):

### File Richiesti:
- `icon-192.png` - 192x192 pixel (per mobile)
- `icon-512.png` - 512x512 pixel (per desktop)

### Specifiche:
- **Formato**: PNG
- **Dimensioni**: 
  - 192x192 px (icon-192.png)
  - 512x512 px (icon-512.png)
- **Contenuto**: Logo Tradelia AI
- **Sfondo**: Trasparente o colorato (consigliato: trasparente)
- **Stile**: Quadrato, logo centrato

### Come Creare:
1. Usa il logo Tradelia AI esistente
2. Ridimensiona a 192x192 e 512x512
3. Salva come PNG
4. Posiziona in questa cartella (`/icons/`)

### Strumenti Online:
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator

---

*Le icone sono necessarie per la PWA (aggiunta al desktop/mobile)*
